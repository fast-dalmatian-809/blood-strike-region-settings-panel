# Blood Strike Region Settings Panel — feature reference

Use the Blood Strike region settings panel workspace to move between connection notes, region fields, and configuration records. The section map below gives each part a clear place in the project.

| Section | Description |
|---|---|
| Connection notes | A dedicated section for connection notes and the configuration details associated with that area. |
| Region fields | A dedicated section for region fields and the configuration details associated with that area. |
| Configuration records | A dedicated section for configuration records and the configuration details associated with that area. |

The project page follows the same section structure.
